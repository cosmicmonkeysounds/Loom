On Windows/Linux, read `⌘` as `Ctrl`.

**The shell**

| Key | Does |
|---|---|
| `⌘1` / `⌘2` / `⌘3` | Writing / Run / Integrations mode |
| `Esc` | in Run, while being someone: back to the Operator |
| `⌘B` | toggle the left rail |
| `⌘⌥B` | toggle the properties tray |
| `⌘\` | toggle the story-graph pane (Writing) |
| `⌘P` | command palette — go to file |
| `⌘⇧P` | command palette — run command |
| `⌘⇧O` | go to symbol in file (`#` prefix = workspace) |
| `⌘,` | settings |
| `⌘/` or `F1` | this help |
| `⌘Z` / `⌘⇧Z` | undo / redo structural story edits (outside the text editor) |

**Files & tabs**

| Key | Does |
|---|---|
| `⌘S` / `⌘⇧S` | save / save all |
| `⌥W` | close tab |
| `⌥⇧T` | reopen closed tab |
| `⌥[` / `⌥]` | previous / next tab |
| `⌥1`…`⌥9` | jump to tab N |

**In the text editor**

| Key | Does |
|---|---|
| `F12` or `⌘Click` | go to definition |
| `⇧F12` | find references |
| `F2` | rename the beat at the cursor, project-wide |
| `⇧Right-click` | native browser context menu |

**On the story graph**

| Key | Does |
|---|---|
| arrow keys | walk selection to the nearest node |
| `Enter` | drill into a beat / expand a collapsed file |
| `Esc` | back out of a drill-in / clear selection |
| `F2` | rename the selected beat |
| `Delete` | delete the selected beat |
| double-click | drill in (beat) / edit in place (block) / create (ghost node) |

**In cockpit chat (Run)**

| Key | Does |
|---|---|
| `Enter` | send |
| `⇧Enter` | newline |
