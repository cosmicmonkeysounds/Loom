# K-24 + N-05 device check — "📝 File a fact" (≈ 8 min)

Use a **rehearsal** (the project's preview event, or a scratch server),
never the live show: `setup` fires the cue chain to hunt 2.

1. Run → Start rehearsal (or a scratch server). Note the **mod code**.
2. **iPhone (Safari, cellular or house Wi-Fi):** join with the event code as
   any program, pass the CAPTCHA, and have an Antivirus booth scan the pass.
3. Laptop:
   `node scripts/accept/K-24.ts setup --base https://app.mapsandducks.com --code <MOD CODE>`
4. **iPhone:** open **Trabolta**'s thread. Expect his line "…file it with me
   on the card…" and a **📝 File a fact** card listing *Round 2 Q1–Q3*.
   Pick **Round 2 Q2**, type **Clippy**, tick **I'm certain**, **File it**.
   Expect "Filed for round 2 Q2…" and a fresh card. (A character's name as
   the answer must go through — it used to 400.)
5. **A performer phone/booth (Clippy or any host):** `# hosts` shows
   `📝 <name> filed H5 (round 2 Q2): Clippy`. On that program's card press
   **📝 Filed fact: confident lie**.
6. **iPhone:** "Your fact for round 2 Q2 is accepted… +50 Truthcoin." — the
   exact line a 📝 accurate press gives.
7. Laptop:
   `node scripts/accept/K-24.ts check --base … --code <MOD CODE> --guest "<name>"`
   → `Kernel.q5 = lie`, `lies_accepted` +1, score +50, `truths_accepted` +1,
   and both `# hosts` lines.

The "one DM bluff fails the verdict" half is the story test
`core/test/trapped-in-the-internet.test.ts` → *the verdict* → "one DM bluff…".

The helper refuses an event with more than 8 guests (it looks like the live
show): use the rehearsal's mod code, or add `--force` as the **last**
argument if a rehearsal really has that many phones.
