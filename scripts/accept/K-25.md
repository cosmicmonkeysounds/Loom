# K-25 device check — the awards ceremony (≈ 10 min)

Use a **rehearsal** (the project's preview event), never the live show.
Needs this lane deployed to https://app.mapsandducks.com, and the story
synced (`scripts/sync-show.sh`). The TV parts need lane C's K-18 (TV
voice, `view=tv`) and K-17 (slides beat attract); without them, check the
lines on phones and note the TV as pending.

Setup (2 min): Run → Start rehearsal. Join **3 phones** as guests (any
programs) and get each through the door (an Antivirus scan, or
Inspector → scan as Norton). Open the TV (`/terminal/?…&view=tv`) on the
house Mac. `MOD=<the event's mod code>`; every command below is
`node --experimental-strip-types scripts/accept/K-25.ts <cmd> --base https://app.mapsandducks.com --code $MOD`.

**A. Trabolta hosts (4 min)**

1. `end song` (rehearsal shortcut for an ending) → status shows
   `ended true · ending song`.
2. In Run → Director, the cue sheet's **G1 · 🏆 Start the awards
   ceremony** — click it (or `start`). Phones: an `!` alert, and two
   Trabolta lines in **The Desktop** room. **TV: speaks both lines.**
3. Cue sheet **G2 · 🥇 Most Trusted**: pick phone 1's program in *who?*,
   click. Then **G4 ✈️** on phone 2, and **G7 🎲 Best Liar** on phone 3
   with value `2` (or `three`).
   - each line is in The Desktop with **that program's name** (and its
     number; Best Liar says "Confident lies I accepted: 2");
   - each winner's phone gets "🏆 You won …!";
   - **TV: speaks each line and shows the award slide** (a text card
     until P-2's PNGs land); the slide stays up, not the screensaver.
4. Fire **G9 🎲 Quest Completionist** with an empty value box: the line
   reads with no number.

**B. Clippy hosts after `destroyed` (3 min)**

5. Don't restart (a restart signs the phones out): `end destroyed` also
   re-arms G1.
6. G1 again. The opening lines are **Clippy's** ("The
   computer is off…"), in The Desktop. Clippy's booth shows them: she
   **reads them aloud**. **TV: says nothing** (Trabolta is off) and shows
   `screens_ceremony`.
7. G2 on a phone's program → a Clippy line with the name; **TV shows the
   award slide** over the screensaver.

Pass = A3 lines with names on every phone + the TV speaking them; B6/B7
Clippy's lines on her booth + the TV slide. Run → Restart to clear.

Unit proof (no device): `core/test/trapped-in-the-internet.test.ts` →
*the awards ceremony (K-25)*; `core/test/views.test.ts` → *flags the cues
that need a person*; `editor/src/components/cockpit/cue-sheet.test.ts` →
*person cues*.
