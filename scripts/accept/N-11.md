# N-11 device check — the hold line with no worker online (≈ 5 min)

Use a **rehearsal** (the project's preview event), never the live show.
The VPS must run current master (the server owns the hold line now) with the
story synced (`cast/trabolta.loom` carries `hold:`).

1. **Stop Trabolta's worker** on the house Mac (Ctrl+C the
   `stagehand run … --only agents` window, or quit that terminal tab).
   Run → Mind shows the worker offline.
2. Run → Start rehearsal. Note the **mod code**. Wake Trabolta:
   `node --experimental-strip-types scripts/accept/K-24.ts setup --base https://app.mapsandducks.com --code <MOD CODE>`
   (fires the cue chain through `introduce_trabolta`, so his DM row exists).
3. **Phone:** join as any program and get cleared. Note the program name.
4. Laptop:
   `node --experimental-strip-types scripts/accept/N-11.ts --base https://app.mapsandducks.com --code <MOD CODE> --guest "<program name>"`
5. On the phone, open **Trabolta** and send `hello?`, then (within 15 s)
   `are you there?`.
   → about 20 s after the first message, ONE line arrives from Trabolta:
   *"Jean Trabolta is not responding. Please do not move the mouse."*
   The script prints `hold line after ~20 s (1×)` and `PASS`.
6. **Terminal (optional, 1 min):** scan the same pass at a wall terminal
   in `view=auto` and type a line; ~20 s later the face speaks the hold line.
7. **Restart the worker.** Within a few seconds it answers the waiting
   message for real (the request stayed queued). Run → Restart the
   rehearsal afterwards.

Unit proof (no device): `core/test/agents.test.ts` → *with nobody online,
the hold line is offered once after 20 s…*, *no hold line while a worker…
is online*, *…the authored hold line lands in the guest's thread after
20 s*; `core/test/trapped-in-the-internet.test.ts` → *Trabolta has a
plain-words server hold line*.

The helper refuses an event with more than 8 guests (it looks like the live
show): use the rehearsal's mod code, or add `--force` as the **last**
argument if a rehearsal really has that many phones.
