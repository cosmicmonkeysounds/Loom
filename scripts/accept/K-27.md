# K-27 + N-06 device check — the door code, the server-room cutscene and the patch-bay alarm (≈ 10 min)

Bench H1 (Thu 10-22; recheck 10-28). Use a **rehearsal** (the project's
preview event, or a scratch server), never the live show. Wave 7: the
server-room door has a **standalone keypad lock** (its code is set by hand
on the lock, never networked: nothing in software can lock or unlock it)
and a **wire-loop contact that closes when the door opens**. A chess win or
the majority puts *The Door Code* in the winner's phone Codex; the keypad
opens with it; the opening starts the server-room cutscene. **The door never
alarms**: only the patch bay does, on the **second** wrong combination.

already working (K-05 / HW-PATCH-07), the keypad lock fitted and
