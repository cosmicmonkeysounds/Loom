# K-27 + N-06 device check — the door code, The Heart and the patch-bay alarm (≈ 15 min)

Bench H1 (Thu 10-22; recheck 10-28). Use a **rehearsal** (the project's
preview event, or a scratch server), never the live show. Wave 7: the
server-room door has a **standalone keypad lock** (its code is set by hand
on the lock, never networked: nothing in software can lock or unlock it).
**Wave 20:** the door sensor is an **LED shining into an LDR** on the frame,
read by the **Grand Central M4** on the server-room laptop, whose terminal
page (`door=serial`) posts **`door_sensor_opened`** / **`door_sensor_closed`**
(never `server_door_opened`, which is now only the director's 🚪 fallback:
pressing it hands the door to the 🚪 buttons, `door_override`, until 🚪
*Trust the door sensor again*, `server_door_trust`). A chess win or the
majority puts *The Door Code* in the winner's phone Codex; the keypad opens
with it; the first opening once Trabolta is awake plays **The Heart**, which
waits for the door to be **shut** before anything goes on. **The door never
alarms**: only the patch bay does, on the **second** wrong combination.

it with both calibrations (⚙; the edges reach the story: `K-05.sh`), or
