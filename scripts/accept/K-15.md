# K-15 — kiosk basics: acceptance

**Pass:** a tablet in Fully Kiosk stays awake 2 h on the charger; a short
tap on ⚙ does nothing. Settings reference: `docs/trapped/kiosk.md`.

Automatic part (desk): `pnpm --filter loom-terminal test` (`kiosk.test.ts`:
the wake lock re-taken on visibility, the 2 s hold).

## Desk check (2 min, any laptop)

1. Open `https://app.mapsandducks.com/terminal/` in Chrome (provision with
   the mod code if asked).
2. Click ⚙ quickly: **nothing happens.** Hold the mouse on ⚙: a bar fills
   under it and setup opens at 2 s. Release at ~1 s: nothing.
3. DevTools Console: `document.documentElement.dataset.wakeLock` →
   `"held"`. Switch to another tab and back, run it again → `"held"`.

## Device check (≤ 10 min hands-on, then a 2 h wait)

On one wall tablet (start it at the 10-20 tablet gate):

1. Fully Kiosk → Settings: apply the table in `docs/trapped/kiosk.md`
   (Start URL, Autoplay Audio, Webcam, no pull-to-refresh, Keep Screen On,
   Screen Off Timer 0, no screensaver, no auto reload on idle, kiosk mode).
2. Provision once with the `/terminal/?code=…&name=…&spot=…` link, then let
   Fully load the Start URL. Tap TOUCH TO WAKE.
3. **Short tap ⚙** (a quick finger tap, three times): nothing opens.
   **Hold ⚙ 2 s**: setup opens. Leave setup the way you found it.
4. Optional, with USB debugging + laptop Chrome `chrome://inspect`:
   `document.documentElement.dataset.wakeLock` → `"held"` (or
   `"unsupported"` on a pre-Chrome-84 tablet — Fully's Keep Screen On then
   does it alone).
5. Leave it on the charger, untouched, and note the time. **Pass** if after
   2 h the screen is still lit on the attract screen (and the ⚙ still needs
   the hold).

Bathroom: the bathroom tablet hangs on the **hall** wall beside the
bathroom door, camera facing the hall, provisioned `spot=bathroom`.
