# K-12 device check — Run → Print sheet (≈ 8 min)

Use the project's **rehearsal** (preview event) on https://app.mapsandducks.com/edit/.
Room signs need K-13 (`?checkin=`, on master) deployed to the VPS; the
sheet itself works without it. K-13 should also refuse
a check-in into a `checkin: false` LOCATION (`LocationDef.checkin`, the
Server Room).

1. Run → (Start rehearsal if needed) → the **Join** card → **🖨 Print sheet…**.
   The sheet opens over the editor: P01… staff badges, F01… invited badges,
   B001… blank badges, R01… location cards — QR + in-world room name + an
   `R-…` code (no Optical Drive, no Internet, no Server Room; hidden rooms are
   tagged "hidden until the story opens it", on screen only, beside the real
   room), S1… 🚻 signs with an `S-…` code and C01… fact cards (title + QR +
   typed code, the digit notes too). Every card has a text code (wave 59).
2. Hover any card (screen only): its link must start
   `https://app.mapsandducks.com/?code=` — **no IP, no port**. A red bar in the
   toolbar means the codes point somewhere else; fix that first.
3. Skip any room you don't want with its **skip** button.
4. **Print… → PDF** from **Safari** at 100%. Expect: every QR present, no broken
   images, toolbar/notes absent from the PDF, 10 badges or location cards a
   sheet, 20 fact cards a sheet, each footer's line 1 inch long.
   No 429 is possible: QRs are drawn in the browser (no `/api/qr` calls —
   Safari's Web Inspector → Network shows none).
5. Print one sheet of each and hand them to K-07: scan a B-badge, an F-badge,
   a P-badge, an S-sign, a C-card and an R-card with an iPhone and an Android,
   **Wi-Fi off**. B → the picker, no event code to type; F → *You are …*;
   P → that part's upload; S → Bathroom Mode; C → the Codex unlocks after
   joining; R → that room's chat (after K-13).

Unit proof (no device): `editor/src/lib/print-sheet.test.ts`,
`core/test/print-sheet.test.ts`, `core/test/codex.test.ts` (*codes lists QR links*).
