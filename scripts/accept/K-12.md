# K-12 device check — Run → Print sheet (≈ 8 min)

Use the project's **rehearsal** (preview event) on https://app.mapsandducks.com/edit/.
Room signs only *do* something once K-13 (lane B, `?checkin=`) is merged
and deployed; the sheet itself works without it.

1. Run → (Start rehearsal if needed) → the **Join** card → **🖨 Print sheet…**.
   The sheet opens over the editor: J1 join poster, C01… codex posters
   (title + QR + typed code), R01… room check-in signs (no Mud Room, no
   Internet; hidden rooms are tagged "hidden until the story opens it").
2. Look at the small blue link under any card (screen only): it must start
   `https://app.mapsandducks.com/?code=` — **no IP, no port** (else K-01's
   `LOOM_PUBLIC_URL` isn't set on the VPS yet; fix that first).
3. Untick a room you don't want (e.g. The Server Room) with its **skip**
   button; pick **4 per page**.
4. **Print… → PDF** from **Safari**. Expect: every QR present, no broken
   images, toolbar/notes/links absent from the PDF, 4 cards per Letter page.
   No 429 is possible: QRs are drawn in the browser (no `/api/qr` calls —
   Safari's Web Inspector → Network shows none).
5. Print one page and hand it to K-07: scan J1, one C-poster and one
   R-sign with an iPhone and an Android, **Wi-Fi off**. J1 → join screen
   for this event; C → the Codex unlocks after joining; R → that room's
   chat (after K-13).

`core/test/print-sheet.test.ts`, `core/test/codex.test.ts` (*codes lists QR links*).
